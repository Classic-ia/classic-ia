Regras por Tipo de Rescisao
Sem Justa Causa
Paga: Saldo de salario + 13o proporcional + Ferias proporcionais + 1/3 ferias + Ferias vencidas + 1/3 ferias vencidas + Aviso previo indenizado + Multa 40% FGTS
Desconta: INSS + IRRF (se aplicavel)
Pedido de Demissao
Paga: Saldo de salario + 13o proporcional + Ferias proporcionais + 1/3 ferias + Ferias vencidas + 1/3 ferias vencidas
NAO paga: Aviso previo (se nao cumpriu) + Multa FGTS
Desconta: INSS + IRRF + Aviso previo (se nao cumpriu)
Justa Causa
Paga: Saldo de salario + Ferias vencidas + 1/3 ferias vencidas
NAO paga: 13o proporcional + Ferias proporcionais + 1/3 ferias proporcionais + Aviso previo + Multa FGTS
Acordo (Art. 484-A CLT)
Paga: Saldo de salario + 13o proporcional + Ferias proporcionais + 1/3 ferias + Ferias vencidas + 1/3 ferias vencidas + 50% do Aviso previo + 20% Multa FGTS
Desconta: INSS + IRRF
Termino de Contrato de Experiencia
Paga: Saldo de salario + 13o proporcional + Ferias proporcionais + 1/3 ferias + Ferias vencidas + 1/3 ferias vencidas
NAO paga: Aviso previo + Multa FGTS
Formulas de Calculo:
Saldo de salario: (salario / 30) x dias trabalhados no mes
13o proporcional: (salario / 12) x meses trabalhados no ano (15+ dias = mes cheio)
Ferias proporcionais: (salario / 12) x meses desde ultimo periodo aquisitivo
1/3 de ferias: ferias proporcionais / 3
Ferias vencidas: salario integral (se periodo aquisitivo completo sem gozo)
Aviso previo indenizado: salario base + 3 dias por ano de servico (maximo 90 dias total)
Multa FGTS 40%: saldo FGTS x 40% (ou 20% para acordo Art. 484-A)
Tolerancia: diferenca de ate R$ 1,00 e considerada aceitavel.
