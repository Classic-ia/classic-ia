============================================================
 RENOMEADOR DE DOCUMENTOS RH - Classic Couros
 Guia rapido de uso (para qualquer pessoa)
============================================================

O QUE ESTE PROGRAMA FAZ
-----------------------
Ele le os documentos digitalizados do RH (PDF, JPG ou PNG),
descobre sozinho usando Inteligencia Artificial:

  - o nome do funcionario
  - o tipo do documento (holerite, atestado, ponto, etc.)
  - a data de referencia

e entao RENOMEIA e ORGANIZA cada arquivo na pasta certa.

Exemplo de nome gerado:
  JOAO DA SILVA_HOLERITE_2025-05.pdf

------------------------------------------------------------
COMO ABRIR O PROGRAMA
------------------------------------------------------------
1) De um duplo clique no arquivo  INICIAR.bat
2) Se aparecer um aviso dizendo que o Python nao esta
   instalado, o programa vai abrir o site para voce baixar.
   - Baixe e instale o Python.
   - MUITO IMPORTANTE: na tela de instalacao, marque a
     caixinha "Add Python to PATH" antes de clicar em
     "Install".
   - Depois de instalar, abra o INICIAR.bat novamente.

------------------------------------------------------------
PASSO A PASSO NA TELA DO PROGRAMA
------------------------------------------------------------
1) CHAVE API GEMINI (obrigatoria):
   Cole aqui a chave do Google Gemini.
   Onde conseguir (e gratis):
     https://aistudio.google.com/apikey
   Faca login com a conta Google, clique em "Create API key"
   e copie o codigo que aparecer.

2) CHAVE API CLAUDE (opcional, mas recomendada):
   Serve como "reserva" caso o Gemini fique sobrecarregado.
   Onde conseguir:
     https://console.anthropic.com/  (menu API Keys)
   Se voce nao tiver, deixe em branco - o programa funciona
   so com o Gemini.

3) PASTA DE ORIGEM:
   Clique em "Procurar..." e escolha a pasta onde estao os
   documentos que precisam ser renomeados.

4) PASTA DESTINO (raiz do RH):
   Clique em "Procurar..." e escolha a pasta principal do RH
   onde os documentos organizados devem ficar. O programa
   cria sozinho as subpastas (HOLERITES, ATESTADO, etc.).

5) INTERVALO ENTRE ARQUIVOS:
   Deixe em 10 segundos (recomendado). Esse tempo evita que
   o Google bloqueie temporariamente por uso excessivo.

6) MOVER ou COPIAR:
   - Marcado  = MOVE os arquivos (some da pasta de origem).
   - Desmarcado = COPIA (mantem os originais onde estavam).
   Na duvida, DESMARQUE para fazer um teste sem risco.

7) Clique no botao verde  INICIAR.

------------------------------------------------------------
DURANTE O PROCESSAMENTO
------------------------------------------------------------
- A barra mostra o quanto ja foi feito (em %).
- O "Provedor" mostra qual IA esta sendo usada no momento
  (GEMINI ou CLAUDE).
- O registro embaixo mostra tudo que esta acontecendo, com
  cores:
     Verde   = arquivo renomeado com sucesso
     Vermelho= deu erro nesse arquivo
     Amarelo = aviso / aguardando
     Azul    = informacao
     Roxo    = esta usando o Claude como reserva

Botoes:
  PAUSAR/RETOMAR (laranja) - pausa e continua quando quiser.
  PARAR (vermelho)         - encerra o processamento.

------------------------------------------------------------
SE VOCE FECHAR NO MEIO
------------------------------------------------------------
Sem problema! Da proxima vez que iniciar com a MESMA pasta
de origem, o programa pergunta:
  "Encontrei X arquivos ja processados. Deseja continuar
   de onde parou?"
- Responda SIM para continuar de onde parou (nao refaz o
  que ja deu certo).
- Responda NAO para recomecar tudo do zero.

------------------------------------------------------------
RELATORIO FINAL
------------------------------------------------------------
Ao terminar, o programa cria um arquivo CSV na pasta de
destino, com o nome comecando por "relatorio_renomeacao_".
Ele lista, para cada documento:
  arquivo original | novo nome | pasta | provedor | status |
  confianca da leitura

Voce pode abrir esse relatorio no Excel.

------------------------------------------------------------
DICAS E OBSERVACOES
------------------------------------------------------------
- "Confianca BAIXA" significa que a IA nao teve muita certeza;
  vale a pena conferir esses arquivos manualmente.
- O programa nunca apaga documentos: na pior das hipoteses
  ele coloca o arquivo na pasta OUTROS.
- Arquivos com nomes iguais nao se sobrescrevem: o programa
  adiciona _1, _2, etc. automaticamente.
- As chaves de API e as pastas ficam salvas para a proxima
  vez (arquivo config.json, ao lado do programa).
- Voce nao precisa instalar mais nada alem do Python.

------------------------------------------------------------
PROBLEMAS COMUNS
------------------------------------------------------------
- "Informe a Chave API Gemini": voce esqueceu de colar a
  chave do Gemini.
- Muitos erros 429 / "limite": o Google esta limitando o
  uso gratuito. O programa espera e tenta de novo sozinho;
  se persistir, aumente o intervalo para 20 ou 30 segundos.
- A tela nao abre: confirme que o Python foi instalado com
  a opcao "Add Python to PATH" marcada.

Qualquer duvida, fale com o setor de TI da Classic Couros.
